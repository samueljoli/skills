NETWORKS / A VISUAL PRIMER

One message.
Seven layers.

What happens between an idea on your screen and a signal on a wire?

The OSI model divides network communication into seven responsibilities. Read down the stack to follow a message from software to signals.

THE OSI MODEL4 MIN READ
↓ Follow the layers
LAYER 07MEANING

Application

Application protocols define the exchanges software uses to request and deliver information.

A REQUEST, BEFORE THE JOURNEYGET /hello HTTP/1.1
Host: example.com

HTTP gives this request a meaning: retrieve a resource. The lower layers carry the request without needing to understand the page.

EXAMPLEHTTP · SMTP
LAYER 06REPRESENTATION

Presentation

Presentation concerns how information is represented, including encoding, compression, and encryption.

CHARACTERA
→
UTF-8 BYTE01000001

Two systems need a shared interpretation of the bytes they exchange. In real Internet software, these responsibilities can live across several protocols and libraries.

QUESTIONHow should these bytes be interpreted?
LAYER 05CONVERSATION

Session

The session layer organizes a conversation: establishing it, coordinating it, and closing it.

OPENEXCHANGECLOSE

Imagine a long exchange with agreed checkpoints. Keeping track of the conversation is a separate concern from transporting each individual piece.

QUESTIONWhere are we in the conversation?
LAYER 04END TO END

Transport

Transport provides communication between endpoints. TCP adds ordered, reliable delivery; UDP provides datagrams without those guarantees.

A BYTE STREAM, CARRIED IN PIECES
01020304…

With TCP, a receiver acknowledges received data. Missing bytes can be retransmitted, while the application sees an ordered stream.

EXAMPLETCP · UDP
LAYER 03DESTINATION

Network

The network layer addresses packets and moves them along routes toward their destination.

IP PACKET / SCHEMATIC
IP HEADERPAYLOAD
DESTINATION 192.0.2.8

Each router chooses a next hop. The packet can cross many links before it reaches the destination network.

EXAMPLEIP
LAYER 02ONE LINK

Data link

The data link layer carries frames across a local link between connected network devices.

ETHERNET FRAME / SCHEMATIC
LINK HEADERIP PACKETCHECK

A packet can be wrapped in an Ethernet frame for one hop and a different kind of frame for another. The link changes; the destination still matters.

EXAMPLEEthernet · Wi-Fi
LAYER 01THE PHYSICAL WORLD

Physical

The physical layer transmits bits through a medium using electrical, optical, or radio signals.

BITS → SIGNAL / SIMPLIFIED

A bit is an abstraction. On a real link, a receiver measures a physical signal and interprets it using an agreed signaling scheme.

MEDIUMCopper · Fiber · Air

PUTTING IT TOGETHER

A model for thinking.

OSI is a conceptual framework. The Internet’s actual protocol stack does not map neatly to all seven layers.

Use the layers to ask a more precise question. Is the signal missing? Is the next hop unreachable? Did the application reject the request?
